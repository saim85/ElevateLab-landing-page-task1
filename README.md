# Task 1 – Responsive Landing Page (HTML & CSS)

A clean, modern and fully responsive landing page built for the **Web Development Internship – Task 1**.

## What I built
A landing page for a fictional brand called **Lumina** with:

- **Header** – logo + navigation links; collapses into a hamburger menu on small screens (CSS-only, no JavaScript)
- **Hero section** – heading, paragraph, two call-to-action buttons and a floating CSS-only mock browser illustration
- **Features section** – six cards laid out with **CSS Grid**
- **Stats section** – laid out with **Flexbox**
- **Call-to-action banner**
- **Footer** – quick links and social icons (inline SVG)

## Concepts used
HTML5 semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`) • CSS3 variables • Flexbox • Grid • Media queries • Gradients • Transitions & keyframe animations • Mobile-friendly design • `prefers-reduced-motion` support

## Responsive breakpoints
| Width | Behaviour |
|-------|-----------|
| > 960px | Two-column hero, 3-column feature grid |
| ≤ 960px | Single-column hero, 2-column feature grid |
| ≤ 768px | Navigation collapses into a hamburger menu |
| ≤ 560px | 1-column features, full-width buttons |
